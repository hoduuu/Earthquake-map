# 지진 지도 프로토타입

대한민국(및 주변 해역) 지진 지도 브레인스토밍용 데모입니다.

`index.html` 하나만 열면 됩니다. 데이터 소스는 **USGS(미국 지질조사국) Earthquake API**로,
키 발급 없이 즉시 쓸 수 있고 브라우저 CORS도 지원해서 서버나 별도 스크립트 없이
정적 HTML 파일 하나로 동작합니다.

## 사용법

`index.html`을 브라우저로 엽니다 (더블클릭). 화면 상단 패널은 **"지진" / "미군기지" 가로 탭**으로
나뉘어 있습니다. 탭 이름을 클릭하면 그 레이어의 설정이 보이고, 탭 옆 체크박스는 지도에
그 레이어를 표시할지 말지를 결정합니다 — 이 둘은 서로 독립적이라, 예를 들어 "미군기지" 탭을
보고 있어도 "지진" 체크가 켜져 있으면 지도엔 지진이 계속 표시됩니다.

### 지진 탭

- **시작연도 / 종료연도**: 조회할 기간 범위 (기본 1900~올해)
- **최소 규모**: 이 규모 미만은 표시 안 함 (기본 2.5)
- **한국 인근 / 전 세계 / 나라 선택(복수 가능)**: 조회 범위. "나라 선택"을
  고르면 아래 목록에서 체크박스로 여러 나라를 동시에 선택할 수 있습니다.
- **타임라인 재생**: "재생"을 누르면 마지막으로 불러온 지진이 발생 시각 순서대로
  하나씩 나타납니다. 배속(1x~50x) 선택 가능, 슬라이더를 직접 끌어서 특정 시점으로
  바로 이동할 수도 있습니다.
- **연도별 발생 건수 차트**: 현재 조회 결과의 연도별 막대그래프.

조건을 바꾸면 대부분 자동으로 다시 조회하고, "다시 조회" 버튼으로도 수동 갱신 가능합니다.

### 미군기지 탭

뉴스에 자주 나오는 해외 대형 미군기지(한국·일본·유럽·중동·아메리카 등) 32곳을 위치만
표시합니다. 나라별 분류나 필터는 없고, 체크박스 하나로 켜고 끕니다. 마커가 겹치면
지진처럼 클러스터링됩니다.

### 전역 설정 (탭과 무관하게 항상 적용)

- **국경선 표시**: 전 세계 국경선을 은은한 회색 선으로 지도에 항상 깔아둡니다. 나라
  선택 탭에서 나라를 고르면 그 나라만 마젠타색으로 부드럽게 빛나는 형광펜 스타일로
  강조됩니다(테두리 + 반투명 채움 + glow).
- **다크 모드**: 선택은 브라우저에 기억됩니다.
- **링크 복사**: 현재 조회 조건(기간/규모/범위/나라/다크모드)이 URL에 반영되어, 같은
  화면을 다른 사람과 공유할 수 있습니다.

그 외 좌하단 **범례**에 마커 색상(규모 3 미만/3~5/5 이상)과 미군기지·국경선 표시가
정리되어 있습니다.

## 한계

- 나라별 조회는 원래 대략적인 사각형(bounding box)으로만 했는데, 이제 실제
  국경 도형(무료 GeoJSON, 키 불필요)을 불러와서 그 도형의 bbox로 조회하고
  도형 안에 있는 지진만 남기도록 개선했습니다. 도형을 못 구하는 나라나
  날짜변경선을 가로지르는 나라(러시아 등 — 경도 범위 계산이 깨짐)는 여전히
  손으로 잡은 사각형 근사치로 대체됩니다(코드의 `COUNTRIES`). 국경 도형
  자체도 저해상도 근사치라 아주 미세한 경계 오차는 남을 수 있습니다.
- 전 세계 데이터라 한국 내 소규모 지진(특히 규모 2점대 이하)은 기상청 자체
  관측망보다 덜 촘촘하게 잡힐 수 있습니다. 정밀한 국내 이력이 필요하면
  기상자료개방포털(data.kma.go.kr)의 지진 이력 API(별도 회원가입/키 필요)를
  검토하세요.
- 나라를 여러 개 선택하면 나라 수만큼 병렬로 API를 호출합니다 — 너무 많이
  선택하면 응답이 느려질 수 있습니다.
- "국경선 표시"는 전 세계 약 180개국 도형을 한 번에 그리기 때문에, 국경 데이터를
  처음 받아오는 순간(및 저사양 기기)에서는 잠깐 버벅일 수 있습니다. 이후엔 브라우저
  캐시 덕분에 빠릅니다.
- "링크 복사"는 브라우저 클립보드 API를 쓰는데, `file://`로 연 페이지에서는
  브라우저가 이를 차단할 수 있습니다(보안 정책). 이 경우 알림창이 뜨니 주소창의
  URL을 직접 복사하면 됩니다.
- 이 페이지는 이 코드를 작성한 개발 환경의 네트워크 정책상 USGS와 국경
  도형 서버(raw.githubusercontent.com) 접속이 막혀 있어 직접 실행 테스트는
  못 했습니다 — 브라우저에서 열어보고 결과나 에러를 알려주시면 같이
  고치겠습니다.
- 에러 처리, 캐싱 등은 최소한만 되어 있습니다 — 말 그대로 데모입니다.

## 이전에 시도했던 방식 (폐기)

처음엔 기상청 공공데이터포털 API로 국내 공식 데이터를 쓰려 했지만, 해당 API가
조회 기간을 오늘 기준 최대 3일로 제한해("최대 조회 기간은 오늘 기준으로 3일
전까지입니다") 과거 이력을 보려는 목적에 맞지 않아 USGS로 전환했습니다.
